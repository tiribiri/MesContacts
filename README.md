# Mes contacts
Application Android pour gérer une liste de contacts : consulter, modifier, appeler, envoyer un e-mail et changer la photo.

## Fonctionnalités
- Liste des contacts (photo, nom, prénom, téléphone)
- Modification d'un contact
- Appel et envoi d'e-mail
- Photo depuis la galerie ou la caméra

## Technologies
- Kotlin, XML
- Min SDK 24 / Target SDK 34

## Installation
1. Cloner le dépôt
2. Ouvrir avec Android Studio
3. Lancer sur un émulateur ou un appareil
